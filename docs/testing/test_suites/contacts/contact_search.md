# Contact Search
---

## Search by full first name

### Preconditions

- Create test contacts with distinct names and numbers, including a matching and nonmatching contact.

### Steps

1. Open new conversation recipient selection.
2. Enter the search text described above.
3. Compare the results with the test contacts. Clear the search afterward.

### Expected Result

- Results follow the supported search rules. No unrelated recipient is selected.

### Review Status

Draft: confirm the expected result against the implementation and on a test device before release testing.
