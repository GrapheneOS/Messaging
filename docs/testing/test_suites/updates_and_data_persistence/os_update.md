# Os Update
---

## Update GrapheneOS with Messaging installed

### Preconditions

- Use a disposable test device with a supported older build and a compatible signed update. Do not clear app data.

### Steps

1. On the older build, create the data or configuration named in the title and record its exact values, counts and identifiers.
2. Update Messaging or GrapheneOS as required by the test, then open Messaging.
3. Repeat the relevant operation or inspect the same records and compare with the pre-update baseline.

### Expected Result

- The tested data and settings remain available, without loss or duplicates. The tested feature still works.

### Review Status

Test the actual old and new builds. Source review alone cannot confirm update compatibility.
