# Widget Contact Updates
---

## Add a name to a contact previously displayed only by phone number

### Preconditions

- Configure both widget types on the launcher with test conversations.

### Steps

1. Record the initial widget content and corresponding conversation state.
2. Add a name to a contact previously displayed only by phone number.
3. Return to the launcher and compare the affected widget with the conversation or Contacts data; check unrelated widgets remain associated with their original conversations.

### Expected Result

- The displayed identity reflects the current permitted Contacts data; message history and conversation association remain unchanged.

### Review Status

Draft: confirm the expected result against the implementation and on a test device before release testing.
