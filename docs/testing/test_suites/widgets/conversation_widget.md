# Conversation Widget
---

## Add a widget for a specific conversation

### Preconditions

- Configure the Conversation Widget on the launcher with test conversations.

### Steps

1. Record the initial widget content and corresponding conversation state.
2. Add a widget for a specific conversation.
3. Return to the launcher and compare the affected widget with the conversation or Contacts data; check unrelated widgets remain associated with their original conversations.

### Expected Result

- The affected widget reflects the resulting data or configuration without displaying stale or unrelated conversation content.

### Review Status

Draft: confirm the expected result against the implementation and on a test device before release testing.
