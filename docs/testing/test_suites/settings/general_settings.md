## Open application settings

### Preconditions

- Record the initial value of the targeted setting; use a disposable conversation for blocking tests.

### Steps

1. Open Messaging settings or the relevant conversation settings.
2. Open application settings.
3. Leave the screen and reopen the setting; inspect the targeted conversation or subscription if applicable.

### Expected Result

- The selected setting or action is reflected in the correct scope and does not unintentionally modify unrelated settings.

Draft: confirm the expected result against the implementation and on a test device before release testing.
